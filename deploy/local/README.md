# Local Single-Compose Deployment

This directory contains the necessary configuration files and automation scripts to deploy the LOLA application locally in a single Docker Compose environment.

## Directory Contents

* **`Makefile`**: Orchesrates the local deployment workflow. Runs requirements check, config generation, cert creation, Docker Compose setup, and Symfony migrations/fixtures.
* **`configure_local.py`**: A helper python script that reads Ansible variables and generates matching local configuration files (`.env` files for lolapy, frontend, and Docker Compose) along with basic auth htpasswd configurations for the registry.
* **`docker-compose.local.yml`**: The unified Docker Compose configuration file defining all local services (frontend, Python backend, mysql database, private registry, phpmyadmin, and sftp).
* **`sftp.sh`**: A simplified local SFTP monitor script that runs in an infinite loop on the host, scanning the SFTP upload folder for new files every second and invoking the backend API decryption/import endpoint.
* **`auth/`**: Generated directory holding the `htpasswd` registry credentials.

## Getting Started

### 1. Generate local configs and start the app
Run the deploy workflow using `make`:
```bash
make deploy
```
This will automatically:
1. Validate python3.12 and docker are installed on your host.
2. Generate all local `.env` configuration files.
3. Build all necessary backend and frontend images.
4. Spin up the unified docker-compose environment.
5. Create and load the Symfony database schema, migrations, and fixtures.
6. Print the generated SSL certificate and SFTP connection credentials on screen.

> [!WARNING]
> You need to copy the certificate generated by this command to `lola_toolbox/src/crypto.py` for lola toolbox to work.

### 2. Run the SFTP Upload Monitor
For SFTP uploads to work properly, you need to run the `sftp.sh` monitoring script in a separate terminal. This script listens for new files in the upload directory and automatically triggers the backend import API:
```bash
./sftp.sh
```

### 3. Available Commands
Use `make help` (or just run `make` without targets) to list all available Makefile targets:
```bash
make help
```
